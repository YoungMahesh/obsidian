# Research to note

1. Read the target note first; match its existing sections and formatting.
2. Condense the pasted material to facts only: defaults, limits, ranges, semantics, gotchas. Cut filler prose, ASCII diagrams, repeated examples, editorial or temporal notes ("recently added"), and commentary about the source.
3. Insert into the relevant existing section, or a new section in a logical place.
4. Present the exact markdown to insert plus its insertion point, and wait for approval. If the new facts contradict the note, surface the conflict and ask which wins.
5. Apply approved edits literally. Treat follow-up "remove X / include Y" as edits to the proposal, not the note, until approved.
6. Reply with one line naming the file and section changed.
